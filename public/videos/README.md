# Diretório de Vídeos em Libras (`public/videos/`)

Coloque aqui os vídeos `.mp4` gravados com a **Profª Scassiotti** sinalizando cada frase.
O jogo **já está 100% preparado**: assim que um arquivo `.mp4` com o nome correspondente for salvo nesta pasta, a **Tela de Vídeo da Professora** passará a exibir o vídeo automaticamente antes da rodada (com controle de velocidade `1x Normal` / `0.5x Lento`, `Pausar` e `Repetir`).

Enquanto o arquivo `.mp4` não estiver presente, o jogo exibe automaticamente o **Palco Visual de Sinalização da Profª Scassiotti** com o contexto motivacional e o passo a passo dos 3 sinais (`1º QUEM`, `2º AÇÃO`, `3º ALVO`), além de um botão **"Testar arquivo .mp4"** para carregar qualquer vídeo diretamente do computador durante testes ou apresentações.
